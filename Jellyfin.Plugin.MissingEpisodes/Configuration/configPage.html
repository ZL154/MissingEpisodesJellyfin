Sonarr configuration

Jellyfin source uses your library's missing-episode items when available. For the best results, enable Display missing episodes within seasons in Jellyfin → Libraries — you'll get titles, air dates, and thumbnails. Without that, the plugin falls back to gap detection: it finds numbering holes (E01, E02, E03 missing, E04) but can't flag whole missing seasons or trailing episodes.
